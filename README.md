# Gauri Patel (Gxuri) · Portfolio

Personal portfolio of **Gauri Patel (Gxuri)**, a full stack developer in Ahmedabad, Gujarat, India, building production web apps with Next.js, React, TypeScript, Tailwind CSS and Prisma.

**Live site:** https://gxuri.is-a.dev

## What's inside

- **Home:** intro, experience, an animated tech stack, live GitHub contribution graph and recent writing.
- **Work:** professional experience plus projects pulled live from GitHub, each with its own detail page (live site, source, stack, what was built).
- **Blog:** articles on Next.js, TypeScript, modern CSS and AI coding agents, each citing its official sources.
- **Résumé:** an embedded PDF preview, PDF download, copy-as-text, education, setup and tools.
- **Connect:** email, LinkedIn, GitHub and X.

## Built with

- [Next.js 16](https://nextjs.org) (App Router, Cache Components, Turbopack)
- [React 19](https://react.dev) and [TypeScript](https://www.typescriptlang.org)
- [Tailwind CSS 3](https://tailwindcss.com)
- [Motion](https://motion.dev) for animation
- [Simple Icons](https://simpleicons.org) for technology logos
- Live data from the GitHub API, cached on the server and refreshed hourly

## Search and AI visibility

- Per-page titles, descriptions, canonical links and share images
- `robots.txt` open to search engines and AI crawlers, plus `sitemap.xml`
- schema.org structured data: Person, WebSite, BlogPosting, SoftwareSourceCode, ProfilePage and more

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

### Environment variables

| Variable | Purpose |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | The public address, e.g. `https://gxuri.is-a.dev` (used for the sitemap, canonical links and share images) |
